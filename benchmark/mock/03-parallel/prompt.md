# MOCK · Параллельные проверки заказа

Построй один процесс BPMN 2.0 с дорожками «Клиент», «Оператор», «Склад», «Финансы».
Событие клиента «Заказ получен» ведёт к задаче оператора «Принять заказ», создающей объект данных «Заказ».
AND запускает параллельно две задачи: склад выполняет «Проверить остатки», финансы — «Проверить оплату».
Обе задачи читают заказ; проверка остатков также читает хранилище «Остатки».
AND-join «Проверки завершены» ждёт обе проверки. Только затем оператор принимает XOR-решение «Можно отгружать?».
При stockAvailable и paymentConfirmed склад выполняет «Отгрузить заказ», затем клиент получает конечный исход «Заказ выполнен».
Иначе оператор выполняет «Отменить заказ», затем наступает конечный исход клиента «Заказ отменён». Отмена — default-ветка.
Отгрузка и отмена взаимоисключающие. Решение и любой конечный исход возможны только после обеих проверок.
