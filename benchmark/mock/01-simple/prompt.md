# MOCK · Согласование доступа

Построй описательную BPMN 2.0: один процесс, дорожки «Сотрудник», «Руководитель», «Администратор».
Событие «Нужен доступ» запускает задачу сотрудника «Подать заявку».
Руководитель выполняет «Рассмотреть заявку», затем XOR «Заявка одобрена?».
При одобрении администратор выполняет «Предоставить доступ», процесс заканчивается событием «Доступ предоставлен».
При отказе руководитель выполняет «Сообщить об отказе», процесс заканчивается событием «Отказ получен» в дорожке сотрудника.
Одобрение и отказ взаимоисключающие; выдавать доступ без рассмотрения или после отказа запрещено.
Ветка одобрения имеет условие approved, отказ является веткой по умолчанию.
