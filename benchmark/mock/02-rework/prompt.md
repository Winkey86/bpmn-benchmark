# MOCK · Доработка документа

Построй один процесс BPMN 2.0 с дорожками «Автор», «Специалист», «Регистратор».
После события «Документ требуется» автор выполняет «Подготовить документ», создавая объект данных «Документ».
Специалист читает этот объект в задаче «Проверить документ».
XOR «Нужна доработка?» при needsRework направляет документ автору на «Доработать документ», после чего повторяется проверка специалистом.
Когда доработка не нужна, ветка по умолчанию ведёт регистратору на «Зарегистрировать документ».
Эта задача читает документ и записывает результат в хранилище «Реестр»; затем наступает «Документ зарегистрирован».
Проверка может повторяться, регистрация выполняется только после принятия документа.
Документ и реестр представлены данными, не задачами и не событиями.
